## About me

I am an economics graduate with a passion for software engineering, data analytics, and technology-enabled problem solving. I enjoy connecting analytical thinking with practical development to build useful applications, explore complex datasets, and make information more accessible.

My interests span full-stack development, financial technology, applied economic research, and AI-powered tools. I value clean code, thoughtful design, reproducible analysis, and continuous learning.
